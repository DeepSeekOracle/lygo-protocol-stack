How this alpha was checked before it was posted (and what the check found)

Nothing here was hand-copied from a working folder. Each installer was compiled from a sealed payload — a read-only, hash-listed copy of the build in the canon vault — and then installed and booted from the installer itself. Before publishing, the installed tree was scanned for credentials and for the steward's own runtime state. Two real findings were fixed: the build was carrying the steward's private transcript archive (778 files) and a bench log, and the shipped config pointed its model scan only at his own vault drive, so an installed copy on any other machine would have booted with no brain. Both were fixed, the four installers rebuilt, and the scan re-run clean: 0 transcript files, no token files, no key-shaped strings in 335 inspected files. Every file on this page carries a SHA-256 you can check; the full digest list is the SHA256SUMS.txt beside the downloads.

1 · Verify the download

CertUtil -hashfile FILE SHA256 on Windows, sha256sum FILE on Linux/macOS. Compare the whole digest against the copy button above or SHA256SUMS.txt. No match → delete it, do not run it.

2 · Install

Run the installer. The light builds are per-user (no admin prompt); PC builds default to D:\, the USB build targets your stick. Then read READ_DISCLAIMER_FIRST.md in the install folder.

3 · Get a model

Light: python fetch_models.py --list, then --profile basic --dest D:\LYGO_MODELS. It reads the pinned manifest, pulls only from our vault, and verifies every SHA-256 before keeping a file. Full installer: skip this — gemma4-12b is already installed.

4 · Boot

Launch LYGO_LLM_CONSOLE.bat, press Scan drives, boot the model. Better hardware later is a drop-in: put a bigger GGUF in models\ and the console boots whatever it finds — no reinstall.

Models come from us, not from someone else's site

Weights live in our vault — huggingface.co/DeepSeekOracle/lygo-console-models (mirror GitHub) — pinned to an immutable revision with a SHA-256 per file, so a download cannot quietly change under you. Default is gemma4-12b (text · image · audio, Apache-2.0) plus an embeddings model and a coder model; the installers carry the pinned manifest and the fetcher, and nothing is pulled from a moving branch or a third-party mirror. Small machine (8–16 GB RAM)? gemma4-12b wants ~32 GB — a smaller Q4 you already own drops straight into models\, and the console boots it.
