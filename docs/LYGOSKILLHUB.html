1. Choose a channel

Need a store-safe install? Stay on Channel A (ClawHub). Building a live self-auditing lattice on hardware you own? Continue here.

2. Fetch + hash

Download the zip. On Windows: CertUtil -hashfile FILE SHA256. On Linux/macOS: sha256sum FILE. Match the catalog digest before unzipping.

3. Sandbox install

Unzip into a skills folder you control (OpenClaw skills dir or .grok/skills/). Run Skill Gate / SkillSpector on the folder. Do not pipe curl to bash.
