================================================================================
B. CLEAN LYRICS (IMPORTANT)
================================================================================

Raw lyric files often contain production notes. We STRIP:

  STYLE:
  STRUCTURE:
  BEAT DIRECTION:
  VOCAL DIRECTION FOR GEMINI:
  chat / “we need to continue…” / AI “for reference only”
  Track headers that are not lyric body

We KEEP only:
  [INTRO] [VERSE n] [CHORUS] [OUTRO] … and the actual lyric lines

Command:
  python D:\lygo-protocol-stack\tools\parse_lyrics_clean.py ^
    --src "C:\Users\justi\Music\BREAKER OF CODES\Track 1 THE SETTLEMENT.txt" ^
    --out "D:\lygo-protocol-stack\data\music_catalog\lyrics\vengeance_codex_lyrics_clean.json" ^
    --album "VENGEANCE CODEX" ^
    --artist "Excavationpro"

Output JSON has tracks[] with title, moniker (THE SETTLEMENT, THE RAT, …), lyrics.

C. ADD ALBUM → STREAM + PLAYLIST + LYRICS INDEX
================================================================================

  cd /d D:\lygo-protocol-stack

  python tools\add_album_to_listen_portal.py ^
    --folder "C:\Users\justi\Music\BREAKER OF CODES" ^
    --album "VENGEANCE CODEX" ^
    --lyrics-json data\music_catalog\lyrics\vengeance_codex_lyrics_clean.json ^
    --encode --publish-hf

If monikers did not match (clean filenames without parentheses), run:
  python tools\_fix_vengeance_lyrics_match.py
  (or extend moniker map for the next album)

Then rebuild the listen HTML hub (embeds playlist):
  python tools\build_public_music_stream.py --hub ^
    --base-url "https://huggingface.co/datasets/DeepSeekOracle/excavationpro-music-stream/resolve/main/stream"

Re-inject lyrics plugin if hub rebuild wiped the script tag:
  Ensure listen-plugins\lyrics-panel.js exists
  Ensure excavationpro-listen.html contains:
    <script src="listen-plugins/lyrics-panel.js?v=1" defer></script>

Copy data files to Excavationpro Pages tree:
  data\lyrics_index.json
  data\public_stream_playlist.json
  listen-plugins\lyrics-panel.js
  excavationpro-listen.html

E. FEEDING MORE LYRICS LATER (YOUR NEXT DROPS)
================================================================================

1) Put new raw .txt next to the songs (or a folder lyrics/).
2) Run parse_lyrics_clean.py → clean JSON.
3) Merge into lyrics_index.json:
   - Match by moniker (THE GHOST) OR by exact title OR by sha256 after audio add
4) Re-upload lyrics_index.json to HF.
5) No need to re-upload audio if tracks already on portal.

When you feed “all lyrics you ever made”:
  - Prefer one file per album or one giant dump with Track N: "TITLE" headers
  - Cleaner = fewer moniker misses
  - We will batch-parse and only store lyric sections
