LYGO-Claw

Sovereign-hardened agent layer — fork/enhance path from OpenClaw with LYGO P0, Hermes, P1 mycelium, Champion personas, and optional 32GB USB supervisor.

For humans (no .exe yet)

LYGO-Claw is Python 3.11+ plus double-click .bat launchers — same idea as an easy installer, without a single packaged .exe today.

  1. Clone or download lygo-claw and open the folder.
  2. Read START_HERE.txt in the repo root.
  3. Double-click launchers\INSTALL_AND_CHECK.bat (installs package + runs self-test).
  4. Double-click launchers\TRY_GATEWAY.bat — expect JSON with "ok": true.

Docs in repo: docs/QUICKSTART_FOR_HUMANS.md, docs/COMMANDS.md, docs/TROUBLESHOOTING.md.
