# Hardware — stock Meshtastic only

LYGO does not ship radios. Flash **upstream** firmware.

| Board | Role |
|-------|------|
| Heltec WiFi LoRa 32 V3 | USB-C starter |
| LILYGO T-Beam / T-Beam Supreme | Handheld, GPS-capable |
| RAK WisBlock Meshtastic starter | Modular; solar later (not in this skill) |

- **NA (CA/US):** 915 MHz ISM  
- **EU:** 868 MHz — do not mix with NA nodes  
- Pair with the Meshtastic app (Bluetooth or USB). This skill never opens the port.  
- Send the `LY1/...` line as a **text** message.  
- Docs: https://meshtastic.org/docs/  
- Firmware: https://github.com/meshtastic/firmware
