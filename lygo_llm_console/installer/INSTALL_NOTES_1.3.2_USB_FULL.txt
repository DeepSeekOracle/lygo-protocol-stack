LYGO Local Agent Console 1.3.2 — USB CLAW, EVERYTHING INCLUDED — what you just installed
========================================================================================

This stick build arrives complete: the chat engine, the picture engine, its own Python, the code
brain, AND the image checkpoint. Nothing to fetch — boot it and draw.

WHAT CAME OUT OF THE INSTALLER
------------------------------
  engine\              the chat engine (llama.cpp + backends)
  python\              the stick's own Python — the machine needs none installed
  tools\sd-cpu\        the PICTURE engine: stable-diffusion.cpp, CPU build, 45 MB,
                       no CUDA, no card, no admin rights
  models\qwen2.5-coder-7b.gguf                 the code brain / fast tasker
  models\sd\v1-5-pruned-emaonly.safetensors    the IMAGE checkpoint — SD 1.5, 4.27 GB
  models\sd\LICENSE-CREATIVEML-OPEN-RAIL-M.txt its licence, travelling with it as it must

PICTURES WORK IMMEDIATELY
-------------------------
    LYGO_AGENT_STICK.bat          the stick's own ports (9651 / 11451)
    LYGO_LLM_CONSOLE.bat          the PC pair of ports (9641 / 11441)

Then ask in plain words — "draw me a lime green sports car in a futuristic neon city" — or use the

No config, no env var, no internet: the console looks for its generators at <kit>\tools\sd-cpu when
the machine it is plugged into has no media root of its own, and the checkpoint sits exactly where it
looks (models\sd). The stick's engine works on any Windows box it meets.

FASTER, OPTIONAL — AND WHY SDXL TURBO IS NOT THE ONE INSIDE
------------------------------------------------------------
SDXL Turbo runs 4 steps instead of SD 1.5's 20, so it is much faster — and its licence (Stability AI,
non-commercial research) does not allow us to redistribute it. SD 1.5's licence (CreativeML Open
RAIL-M) does, with the licence attached, which is why SD 1.5 is the checkpoint that ships. Want
Turbo?

    tools\sd-cpu\FETCH_IMAGE_MODEL.bat        (or the Start-menu entry "Fetch a faster checkpoint")

6.94 GB, once, from Stability's own repository, its licence shown, resumable, byte-count checked, and
a bad file deleted rather than kept. It lands in the same models\sd folder and becomes the default.

THE BIG BRAIN IS THE ONE THING LEFT OUT
---------------------------------------
gemma4-12b (7.4 GB) is not inside: with the coder and the checkpoint, everything together would be a
17 GB installer for a stick. Pull it when you want it —

    python models\fetch_models.py --profile basic      # gemma4-12b + projector, 7.3 GB
    python models\fetch_models.py --profile full       # + coder + embeddings, 12.5 GB

— from our own vault, SHA-256 checked, refused unless the URL is ours. On the studio PC the vault is
already found at I:\LYGO_MODELS, so there is nothing to download there.

WHERE YOUR PICTURES GO
----------------------
    <install>\workspace\images\gen-<stamp>.png

with a receipt naming the route (cpu / cuda), the engine, the checkpoint, the steps, the seconds and
the bytes — "drawn" is something the engine measured, not something the model remembers meaning to do.

VERIFY WHAT YOU DOWNLOADED
--------------------------
    CertUtil -hashfile LYGO_LLM_CONSOLE_1.3.2_USB_SETUP_FULL.exe SHA256

NOTE: 9 GB cannot ride inside one EXE (Windows cannot load a Setup.exe larger than ~4.2 GB), so this
ships as SETUP.EXE plus .bin slices beside it. Keep them together.
