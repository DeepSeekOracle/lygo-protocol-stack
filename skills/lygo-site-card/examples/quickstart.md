# Quickstart

```bash
python scripts/self_check.py
python scripts/site_card.py card https://chatagent.ca/lattice/
python scripts/site_card.py headers https://chatagent.ca/starchart/
python scripts/site_card.py compare https://chatagent.ca/lattice/ https://eternalhaven.ca/lattice/
```

Yield `ALIGNED` means 200 + title + CSP or Referrer-Policy. Missing `security.txt` is named on the card, not invented.
