What this player loads

This is not an offline widget. Visitors to this page run code and load data from outside it:

  • chatagent.ca — the player script and stylesheet, and the channel catalog at /sources/catalog.json. Those files can change after you review them; this page follows that host by design.
  • cdn.jsdelivr.net — hls.js 1.5.18, loaded only if an HLS channel is played, pinned with Subresource Integrity. Every other channel type skips it.
  • rumble.com, player.kick.com, player.twitch.tv, youtube-nocookie.com — whichever platform the current channel belongs to, as that platform's own embed.
  • the HLS stream's host — if a channel is a plain stream, the video element pulls it directly from the host that the catalog names.

Catalog entries are URL-checked before anything is framed or played: https only, no credentials, and an embed must sit on its own platform's domain. Prefer not to depend on our files? Self-host the player and pin the catalog — see embed/README.md.
