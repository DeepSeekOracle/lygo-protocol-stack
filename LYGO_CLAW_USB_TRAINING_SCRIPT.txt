[17:00] What happens under the hood
[VISUAL: User → Dashboard → Gateway :18789 → Ollama :11434 → weights]

NARRATOR:
Data flow for AI parsers:

1. Browser loads static HTML from USB.
2. WebSocket to ws://127.0.0.1:18789 with token auth.
3. Gateway validates origins: null, file:, *, localhost.
4. Gateway routes to Ollama http://127.0.0.1:11434.
5. Ollama loads qwen2.5:3b from USB models/ollama.
6. Response returns to dashboard.

Isolation: HOME/USERPROFILE/APPDATA → lygo-data/ on stick. OPENCLAW_HOME → lygo-claw/ on USB.

LYGO CLAW is the sovereign wrapper — portable form, P0-aligned routing — around a proven gateway runtime.
