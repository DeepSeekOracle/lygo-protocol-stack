1. WHAT LYGO IS (WHY THIS EXISTS)
================================================================================

LYGO is a steward-owned protocol stack: local-first cryptographic / integrity
primitives (P0 Φ-gate, Merkle eggs, badges), public mirrors (GitHub Pages, HF),
and agent skills (ClawHub) that grow a lattice WITHOUT giving remote systems
authority over the user's machine.

Core ethics:
  • Local A/B eggs are source of truth.
  • Public C is mirror only.
  • Mesh D gossips digests, not payloads.
  • Agent lattice E is presence for ALIGNED agents only.
  • Consent for plant / seed / join / publish.
  • NO auto git push, HF upload, ClawHub publish, or social posts unless human asks.

5. HOW EACH LAYER WORKS (WHY + HOW)
================================================================================

----- A · CLASSIC KERNEL EGGS -----
WHY: Stack modules (P0, drivers, champions) must be content-addressed and
     Merkle-rolled so agents refuse load on tamper (QUARANTINE exit 3).
HOW: lygo-kernel-egg-planter builds/anchors eggs under data/kernel_eggs/.
     tools/verify_kernel_eggs.py + tools/verify_all_kernel_layers.py
COMMAND:
  python tools/verify_all_kernel_layers.py --json

----- B · SOVEREIGN SEEDS -----
WHY: Offline / zero-network pins for skills and policy (skill-pin eggs) without
     calling ClawHub at runtime. Complements A; not a duplicate.
HOW: seed_kernel.py --i-consent writes egg + registry atomically with self-verify.
COMMAND:
  python docs/skills/lygo-sovereign-kernel-seeder/scripts/verify_seed.py --json --root data/sovereign_seeds

----- C · EXTERNAL LATTICE ANCHOR (v1.1 hardened) -----
WHY: World network growth via free servers (Pages/HF/Turbo) while protecting user.
     Public is mirror; local wins on conflict.
HOW:
  • verify_public_anchors.py — HTTP GET only; optional report write
  • verify_world_lattice.py — A+B then C; DEFAULT does NOT rebuild docs
  • --refresh-local / --build-manifest are OPT-IN mutators
  • _safe_invoke.py — runpy allowlist; NO os.system
  • sync_external_plan.py — dry plan; snapshot needs --i-consent --execute-local-only
COMMANDS:
  python docs/skills/lygo-external-lattice-anchor/scripts/verify_world_lattice.py --json
  python docs/skills/lygo-external-lattice-anchor/scripts/verify_public_anchors.py --json
  python docs/skills/lygo-external-lattice-anchor/scripts/verify_world_lattice.py --json --refresh-local

SkillSpector notes (addressed in 1.1.0):
  FIXED: os.system auto-builder
  FIXED: verify auto-running manifest/map as side effect
  DECLARED: network GET, report writes, opt-in builders, permissions in claw.json
  ACCEPTABLE: trusted LYGO_STACK_ROOT required; nested AB tool uses subprocess capture no shell

----- D · LIVING MESH -----
WHY: Many machines need a shared view of whether lattice roots match, without
     shipping egg payloads (exfil risk).
HOW: collect_living_mesh_badge.py builds Layer D badge with roots + roots_digest.
     gossip_tick POSTs summaries to /gossip/badge; compare peers; sentinel health.
     node_api_server light_bus fallback if full lygo_stack missing (sparse checkout).
COMMANDS:
  python tools/collect_living_mesh_badge.py
  python tools/verify_living_mesh.py --json --run-sim
  python tools/node_api_server.py --port 8787
  python tools/living_mesh_join.py --i-consent --peer http://127.0.0.1:8787
  python tools/living_mesh_gossip_tick.py --peer http://127.0.0.1:8787

----- E · AGENT LATTICE -----
WHY: Connect LYGO-aligned agents as a public living PRESENCE network (who is
     online / role / alignment / roots digests) without sharing memory or tools.
HOW: agent cards (12KB max), secret patterns, rate limits, TTL, optional hub token.
